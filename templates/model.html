Training Pipeline & Architecture
Methodology matching the student experiment notebook

1. Train/Test Split: The dataset of 2,392 records was split using an 80/20 stratified split (1,913 training, 479 test samples, random_state=42) to preserve the original class imbalance across folds.

2. Feature Scaling: Standard scaling (StandardScaler) was fitted strictly on training features and subsequently transformed on test sets to eliminate data snooping.

3. Target & Feature Isolation: StudentID and GPA were dropped. GPA is a deterministic source of GradeClass; removing it is essential to prevent target leakage and measure authentic predictive capacity.

4. Classifier: DecisionTreeClassifier evaluated via 10-fold StratifiedKFold cross-validation. The model is trained once at application boot and cached in memory for sub-millisecond inference.
